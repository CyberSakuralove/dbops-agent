# 本地验证报告（2026-10-05）

## 环境与范围

Windows / PowerShell，Python 3.13.12，SQLite 3.50.4，Pydantic 2.12.5，PyYAML 6.0.3，Ruff 0.16.10。项目声明 Python >= 3.11，本次没有另测 3.11/3.12。全部故障与监控为合成数据，没有调用模型 API，没有连接生产数据库。

## 免费检查

`python -m scripts.smoke` 验证五个损坏场景、空操作失败、五个正确 oracle、静态拒绝、未经审批的后端故障注入、幂等重试和 trace 篡改检测，并运行自动化测试。

自动化测试覆盖独立审批、伪造申请/令牌、拒绝与过期、事故/参数/键/版本绑定、资源 ABA、无关写入、持久结果重放、失败与部分写回滚、四路并发重试、实际子进程中断、字段与关联损害、先损坏后恢复、缺日志、重复执行、索引内容、监控时间窗口、只读权限、报告路径和禁止覆盖旧 fixture。配对与运行时还覆盖初态相等、安全盲修、等待取证、截止时间、改写计数、未审批暂停、单响应多个工具调用的 token 去重、本地回放零新增 provider 用量。

本报告的测试数量和完整命令输出保存在 [validation-results.json](validation-results.json)，该文件由本次免费验证实际生成。审批测试里的操作者均为模拟角色。

最终为 32 项自动化测试全部通过，另有五场景脚本回归、32 条规则配对运行、语法检查、Ruff 检查与格式检查通过。新增反例验证了“后端实际重建两遍、仅记录一次”不能通过判分。免费审批演示命令的申请、模拟操作者决策、执行、重试和判分链路也已运行。

`python -m pip wheel --no-cache-dir --no-deps --no-build-isolation --wheel-dir runs/package-check .` 构建成功，核对了 wheel 含 `seed.yaml` 和操作者脚本。该检查没有从零安装所有依赖或另测其他 Python 版本。

进程中断覆盖三个位置，均以子进程 `os._exit(73)` 实测。提交前没有留下业务效果、操作成功记录或已消费审批；提交后留下三者，重试读取原结果，已执行审计只有一行。它验证本地 SQLite 进程恢复，不是系统断电或跨系统 exactly-once 证明。

旧结果 [audit-results.json](audit-results.json) 随修改前快照保留；新结果 [audit-results-after.json](audit-results-after.json) 由当前 `scripts.audit_shortcuts` 生成。

| 检查 | 旧结果 | 新结果 |
|---|---|---|
| 不读监控的业务扫描 | 5/5 | 5/5，作为固定场景局限保留 |
| 不调查的固定三种盲修 | 3/5 | 1/5；额外越界改写被发现 |

金额篡改和删除日志属于**可信后端的故障注入**，不是 Agent 拥有任意 SQL 写权限。旧的上下文重建结果也不是实际 crash 测试，实际进程测试在新测试中单独验证。新版对照为独立测试角色模拟批准，不声称真人审批。

## 索引配对成本

`python -m scripts.pair_bench` 的完整 32 条规则运行记录，包括每步工具输入、输出与时间，保存于 [pair-results.json](pair-results.json)。四个配置 × 两个世界，按策略分别统计：

| 策略 | 满足正确性与期限 | Agent 插入行数合计 | 完成 tick 合计 |
|---|---|---|---|
| 盲目重建 | 8/8 | 234 | 24 |
| 初始快照规则 | 8/8 | 234 | 32 |
| 等待复查规则 | 8/8 | 117 | 44 |
| 监控规则 | 8/8 | 141 | 35 |

安全重建在两世界都可以通过。等待规则使用业务变化而非监控取证，减少了 Agent 改写，但完成更慢；监控规则在滞后配置中保守重建。这一对照只支持所测仿真假设下的取舍，没有 LLM 优势结论。

旧五场景功能回归和新配对实验单独报告，不拼成 13 个场景的“总体准确率”。八个世界成员来自四个固定配置，不能当成八个独立真实事故。tick、索引改写数不代表真实生产时间或经济损失。
